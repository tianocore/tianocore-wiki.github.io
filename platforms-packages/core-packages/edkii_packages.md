# EDK II Packages

Within the [EDK II](https://github.com/tianocore/tianocore.github.io/wiki/EDK-II/) project, there are various packages (each sub-directory). To
discuss an issue with a package, or to [contribute](../../development/contribution-guides/code_contributions.md) a code change, please consult with the
package maintainer on the relevant [edk2-devel](mailto:edk2-devel@lists.01.org) email list.

The package maintainers are documented in the
[Maintainers.txt](https://raw.githubusercontent.com/tianocore/edk2/master/Maintainers.txt)
file in the root of the EDK II tree.
