# UDK2015

[UDK](udk.md)2015 is a stable release of portions of [EDK II](../../reference/external-resources/edk_ii.md) project.

## Current UDK2015 Release (2015-09-29)

UDK2015 Support Specifications

1. Support Unified Extensible Firmware(UEFI) specification 2.5.
2. Support Platform Initialization(PI) specification 1.4.
3. Add ACPI 6.0 definitions.
4. Add SMBIOS 3.0 definitions.

Please refer to Features of Release notes:
[https://github.com/tianocore/udk/releases/download/UDK2015/UDK2015-features.txt](https://github.com/tianocore/udk/releases/download/UDK2015/UDK2015-features.txt)
